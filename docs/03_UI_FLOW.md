# 1. UI設計原則

初期MVPでは以下を優先する。

-   スマートフォン縦画面を最優先
-   大きな文字と大きなボタン
-   ゲーム開始までの操作を少なくする
-   ゲーム中に細かい入力を要求しない
-   戻る場所が分かる
-   危険な操作には確認を入れる
-   爆弾ゲームでは残り時間を表示しない
-   究極の2択では会話を邪魔する自動進行をしない
-   参加者登録なしでもゲームを開始できる

# 3. HOME

## 3.1 目的

アプリの入口。

初見でも「何をして遊べるアプリか」がすぐ分かること。

## 3.2 表示要素

``` text
PARTY GAME

[ 💣 爆弾ゲーム ]

[ 😈 究極の2択 ]

--------------------

[ 👥 参加者管理 ]

[ 🔄 出題履歴をリセット ]
```

ゲームは大きなカードまたは大きなボタンとして表示する。

## 3.3 操作

### 爆弾ゲーム

`爆弾ゲーム` をタップ → 爆弾ゲーム「遊び方」へ。

### 究極の2択

`究極の2択` をタップ → 究極の2択「遊び方」へ。

### 参加者管理

`参加者管理` をタップ → 参加者管理画面へ。

### 出題履歴リセット

確認ダイアログを表示。

例：

``` text
出題履歴をリセットしますか？

使用済みの早口言葉と
究極の2択のお題が再び出題されるようになります。

参加者の名前は削除されません。

[ キャンセル ] [ リセット ]
```

# 4. 参加者管理

## 4.1 目的

普段一緒に遊ぶ参加者を登録しておく。

ゲームごとの参加ON/OFFとは分離する。

## 4.2 表示例

``` text
参加者管理

コータ        [ 編集 ] [ 削除 ]
タケシ        [ 編集 ] [ 削除 ]
ユウジ        [ 編集 ] [ 削除 ]

[ ＋ 参加者を追加 ]

--------------------

[ 全員リセット ]

[ HOMEへ戻る ]
```

## 4.3 参加者追加

名前入力 → `追加`

空文字では登録しない。

## 4.4 編集

登録済みの名前を変更できる。

## 4.5 個別削除

削除前に確認する。

## 4.6 全員リセット

全員削除前に確認する。

出題履歴は削除しない。

# 5. 爆弾ゲーム：遊び方

## 5.1 目的

初めての参加者でも30秒程度でゲームを理解できること。

## 5.2 表示内容

``` text
💣 爆弾ゲーム

1. 柔らかいボールを1個用意
2. 爆弾を持った人は早口言葉を言う
3. 成功したら次の人へ渡す
4. 噛んだら最初から言い直し
5. 爆発音が鳴った瞬間に持っていた人が負け
```

特殊指令も簡潔に表示する。

``` text
特殊指令

🔄 リバース
回す方向を逆にする

⏭ 1人飛ばし
次の1人を飛ばす

⏩ 2人飛ばし
次の2人を飛ばす

✌ お前は2回じゃ！
早口言葉を2回連続成功するまで渡せない

👹 お前は3回じゃ！
3回連続成功するまで渡せない

フェイク効果音
音が鳴っても何も起きないことがある
```

画面下部：

``` text
[ 設定へ進む ]
[ HOMEへ戻る ]
```

# 6. 爆弾ゲーム：設定

1画面で設定できることを基本とする。

縦に長くなりすぎる場合は、項目をカード形式で整理する。

## 6.1 今回の参加者

登録者が存在する場合：

``` text
今回の参加者

☑ コータ
☑ タケシ
☐ ユウジ
☑ マサ
```

登録者がいない場合：

``` text
参加者が登録されていません。

登録しなくても遊べます。
最初に持つ人はその場で決めてください。

[ 参加者を登録する ]
```

参加者0人でもゲーム開始可能。

## 6.2 早口言葉

``` text
早口言葉の難しさ

[ おまかせ ]
[ EASY ]
[ NORMAL ]
[ HARD ]
```

初期選択は `おまかせ` を基本とする。

## 6.3 爆発時間

``` text
爆発まで

[ SHORT ]
10〜40秒

[ NORMAL ]
20〜70秒

[ LONG ]
50〜120秒

[ CHAOS ]
10〜120秒
```

初期選択は `NORMAL` を基本候補とする。

## 6.4 特殊指令

``` text
特殊指令

☑ リバース
☑ 1人飛ばし
☑ 2人飛ばし
☑ お前は2回じゃ！
☑ お前は3回じゃ！
```

## 6.5 イベント量

``` text
イベント量

[ 少なめ ]
[ 普通 ]
[ 多め ]
[ 鬼畜 ]
```

初期選択は `普通` を基本候補とする。

## 6.6 フェイク効果音

``` text
フェイク効果音

[ ON / OFF ]
```

初期MVPでは個別のフェイク音選択画面は作らない。

## 6.7 次へ

``` text
[ 早口言葉を決める ]
```

# 7. 爆弾ゲーム：早口言葉確認

## 7.1 目的

ラウンド中に全員が使用する早口言葉を確定する。

## 7.2 表示例

``` text
今回の早口言葉

「生麦 生米 生卵」

難易度：EASY

[ 別のお題 ]

[ これでいく！ ]
```

`別のお題` → 同条件の未使用問題から再抽選。

`これでいく！` → 開始者決定へ。

------------------------------------------------------------------------

# 8. 爆弾ゲーム：開始者決定

## 8.1 参加者が2人以上選択されている場合

``` text
最初に爆弾を持つ人を決めよう

[ ルーレットSTART ]
```

抽選演出後：

``` text
最初は……

コータ！

ボールを持って準備してください。

[ ゲームSTART ]
```

## 8.2 参加者登録なし・選択者なし

``` text
最初に爆弾を持つ人を
その場で決めてください。

準備できたらSTART！

[ ゲームSTART ]
```

## 8.3 参加者1人の場合

ルーレットは省略または簡易表示とする。

ゲーム開始自体は禁止しない。

------------------------------------------------------------------------

# 9. 爆弾ゲーム：ゲーム中

## 9.1 最重要原則

ゲーム中は操作をほぼ要求しない。

スマートフォンはテーブルに置いたまま。

## 9.2 表示

中心に早口言葉を大きく表示する。

例：

``` text
💣

生麦 生米 生卵

噛まずに言えたら次へ渡せ！
```

残り秒数は表示しない。

爆発までの進捗バーも表示しない。

## 9.3 音

ゲームSTARTと同時に：

-   ticking開始
-   爆発タイマー開始
-   特殊指令スケジューラ開始
-   フェイク効果音スケジューラ開始

## 9.4 特殊指令発生時

画面にも短時間、大きく表示する。

例：

``` text
🔄
リバース！
```

または：

``` text
👹
お前は3回じゃ！
```

表示後は早口言葉画面へ戻す。

爆発タイマーは止めない。

## 9.5 フェイク効果音

フェイク音が鳴っても基本ルールは変化しない。

必要であれば短い視覚演出を出してもよいが、初期MVPでは必須ではない。

------------------------------------------------------------------------

# 10. 爆弾ゲーム：爆発

爆発時：

-   ticking停止
-   特殊指令停止
-   フェイク効果音停止
-   爆発音
-   大きな爆発演出

表示例：

``` text
💥💥💥

ドカーン！！

持ってた人の負け！
```

操作：

``` text
[ もう一回 ]

[ HOMEへ ]
```

`もう一回` → 爆弾ゲーム設定または早口言葉選択へ戻す。

同じ使用済み早口言葉は再出題しない。

`HOMEへ` → 全タイマー・音声を停止してHOMEへ。

------------------------------------------------------------------------

# 11. 究極の2択：遊び方

## 11.1 表示内容

``` text
😈 究極の2択

1. 全員でAかBを選ぶ
2. 多数派は抜ける
3. 少数派だけ残る
4. 残った人でもう一度
5. 最後は決定戦！

アプリへの投票入力は不要。
みんなで結果を確認してください。
```

決定戦の説明：

``` text
決定戦

それまで抜けた人も全員回答に復帰。

決勝に残った2人のうち、
片方だけが全体の少数派になったら
その人が負け。

決まらなければ、もう一問！
```

画面下部：

``` text
[ 設定へ進む ]
[ HOMEへ戻る ]
```

------------------------------------------------------------------------

# 12. 究極の2択：設定

## 12.1 出題レベル

``` text
出題レベル

☑ FAMILY
☐ ADULT
☐ HARD
```

複数選択可能。

最低1種類はONにする。

## 12.2 参加者

究極の2択では勝敗・投票をアプリが管理しないため、参加者登録を必須にしない。

初期MVPでは参加者選択をゲーム進行に利用しなくてもよい。

## 12.3 開始

``` text
[ 究極の2択 START ]
```

------------------------------------------------------------------------

# 13. 究極の2択：通常問題

## 13.1 表示

A/Bを最も目立たせる。

例：

``` text
究極の2択

A
毎日パンツだけ
ビショビショ

VS

B
毎日靴下だけ
ビショビショ
```

画面下部：

``` text
[ 次の究極の2択 ]

[ 🔥 決定戦に行く ]
```

## 13.2 進行

アプリは自動で次へ進まない。

参加者同士で会話し、少数派を確認した後に人間がボタンを押す。

## 13.3 次の究極の2択

選択されたレベルの未使用問題から新しい問題を抽選する。

------------------------------------------------------------------------

# 14. 究極の2択：決定戦

`決定戦に行く` → FINALへ。

表示例：

``` text
🔥 決定戦 🔥

全員参加！

A
腕が4本

VS

B
足が4本
```

画面下部：

``` text
[ もう一度、決定戦 ]

[ ゲーム終了 ]
```

決着したかどうかは参加者が判断する。

`もう一度、決定戦` → 新しい未使用問題。

`ゲーム終了` → HOMEまたは終了画面へ。

------------------------------------------------------------------------

# 15. お題枯渇画面

対象条件の未使用問題がなくなった場合：

``` text
この条件のお題を全部使いました。

[ 条件を変更する ]

[ HOMEへ戻る ]
```

HOMEの出題履歴リセットから再利用可能にする。

アプリが勝手に履歴をリセットしない。

------------------------------------------------------------------------

# 16. 戻る操作

## 16.1 設定・遊び方

通常の戻る操作を許可する。

## 16.2 ゲーム中

爆弾ゲーム中にHOMEへ戻る場合は、誤操作防止の確認を入れる。

例：

``` text
ゲームを終了しますか？

爆弾タイマーと音声を停止します。

[ 続ける ]
[ 終了してHOMEへ ]
```

終了を選択したら、すべてのタイマー・音声を停止する。

------------------------------------------------------------------------

# 17. スマートフォンUI

## 17.1 タップ領域

主要ボタンは指で押しやすい十分な高さを確保する。

小さなテキストリンクを主要操作に使用しない。

## 17.2 文字

ゲーム中の重要テキストは大きく表示する。

特に：

-   早口言葉
-   特殊指令
-   究極の2択 A/B
-   爆発

を優先する。

## 17.3 屋外利用

BBQ等を想定し、背景と文字のコントラストを十分に確保する。

# 19. 初回実機テストフロー

スマートフォンで以下を最初から最後まで実行する。

## 爆弾ゲーム

``` text
HOME
↓
爆弾ゲーム
↓
遊び方
↓
設定
↓
早口言葉
↓
開始者決定
↓
START
↓
実際にボールを回す
↓
特殊指令
↓
フェイク効果音
↓
爆発
↓
もう一回
↓
HOME
```

確認：

-   スマホを持たなくても遊べるか
-   早口言葉が離れた位置から読めるか
-   tickingが聞こえるか
-   特殊指令が聞き取れるか
-   爆発が明確か
-   HOMEへ戻った後に音が残らないか

## 究極の2択

``` text
HOME
↓
究極の2択
↓
遊び方
↓
設定
↓
通常問題
↓
次の問題
↓
決定戦
↓
再決定戦
↓
終了
```

確認：

-   A/Bが一瞬で読めるか
-   会話を邪魔しないか
-   次の問題操作が分かるか
-   決定戦の意味が分かるか
-   同じ問題が不用意に再出題されないか

# 20. UI Flow 完了条件

以下が明確であればUI Flow設計完了とする。

-   HOMEから各機能への導線
-   各ゲームの遊び方
-   ゲーム開始前設定
-   爆弾ゲームの開始から爆発まで
-   究極の2択の通常戦から決定戦まで
-   参加者管理
-   出題履歴リセット
-   ゲーム終了・HOME復帰
-   スマートフォンでの主要操作

次工程では、Codexが迷わず実装できる開発ルールと実装指示を整備し、実装を開始する。
